# VR Application

A 3D web application built for the Techdojo technical assessment.

## Overview

This application allows users to:
- Create an account
- Login securely
- Interact with objects in a 3D environment
- Save and load their customized scene

## Technology Stack

Frontend:
- React
- Three.js
- React Three Fiber

Backend:
- Express.js

Database:
- MongoDB

Currently under development.
